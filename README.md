# Mishthi Mahajan Portfolio — GitHub Pages

## Publish

1. Create a public GitHub repository with a `main` branch. Name it
   `YOUR-USERNAME.github.io` for a root website, or `portfolio` (or any name)
   for a website at `https://YOUR-USERNAME.github.io/portfolio/`.
2. Upload the contents of this extracted folder to the repository root.
   `build.py`, `dist/`, and `.github/` must be directly at the root.
   Upload the extracted files, not the ZIP or its enclosing folder.
3. Include the hidden `.github/workflows/deploy-pages.yml` file. GitHub Desktop
   can commit the entire folder including hidden files. If browser upload
   omits it, use Add file → Create new file and enter that exact path, then
   paste the supplied workflow contents.
4. Open Settings → Pages → Build and deployment and select GitHub Actions.
5. Open Actions → Deploy portfolio to GitHub Pages → Run workflow on main.
   After it succeeds, find the live link in Settings → Pages.

Future pushes to main automatically rebuild and publish. If you use a different
branch, edit `branches: [main]` in the workflow. No base URL, repository name,
Node packages, or access tokens need to be configured in the source.

The workflow publishes only `dist/`. Keep `dist/style.css` and `dist/assets/`
in Git: they are source assets and are not regenerated by the build.
The builder converts root paths in the templates to relative output links.
CSS font paths are relative to the stylesheet. The design and content are preserved.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Files to edit
- build.py: shared header/footer, homepage content, and general case-study template.
- content.json: original five projects and their narrative sections.
- images.json: case-study image lists.
- case-epigraphy.html: the detailed Naneghat case study.
- case-earth-news.html: ongoing research at The Earth News.
- dist/style.css: all visual styles; edit directly. The build does not overwrite it.
- dist/assets/: photographs, research images, local fonts, résumé and reports.
- dist/: complete ready-to-host website, including all six project routes.

## Build and preview
Requires Python 3 only, with no extra packages.

    python3 build.py
    python3 -m http.server 8000 --directory dist

Open http://localhost:8000 . Relative links support both domain-root and repository-subfolder hosting. Opening HTML by double-clicking will not load all assets correctly.

## Design and content decisions
Retain cream paper, dark olive, warm tan, handwritten accents and clear original photographs. No blurred illustrations. The opening text sheet is dark olive with cream lettering and tan highlights. Current research uses an olive panel; work category headings and contact use tan. Case studies use tan title sheets, olive navigation and callouts, and framed images.

Preserve the organised work groups, concise copy, source credits and research limitations. Do not add internal editing notes to public pages or invent achievements, dates, or research results. Mishthi is an Associate Researcher at The Earth News, Jammu, India. Her Gulab Singh research is explicitly work in progress; its unpublished draft PDF is not a public download and is not included here.
